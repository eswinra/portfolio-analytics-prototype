# Local Reference Material

This directory holds the original public reports and starter workbook used for local discovery.

- Treat every source file here as read-only.
- Do not publish or commit the source files.
- Do not place non-public or confidential LACERA material here for Claude to inspect without explicit organizational authorization.
- Put derived workbooks, exports, and renders under `../outputs/`.

The project-level permission settings protect this folder from Claude's built-in edit tools, and `.gitignore` excludes the files. Those are safeguards, not substitutes for reviewing commands and tracked files before publication.
