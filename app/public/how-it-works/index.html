How the CIO Monthly slides work

Where the numbers come from, how a report gets onto the slides, how to build them from the template before it's published, and where to find the code.

Open the slides See the code on GitHub

Where the numbers come from

  • Fund results: returns, allocation, flows, geography, market indexes Report PDF LACERA's public CIO Monthly Report on lacera.gov. A program reads the PDF and checks that the report's own totals add up.
  • Economic indicators: inflation, the Fed's rate, unemployment FRED The St. Louis Fed's public database, as the figures stood on the report's date, so they match what the report printed.
  • Dollar index, themes, items for attention Typed in Written parts of the newest report, entered with their page numbers.
  • Everything, before a report is published Template Your team's own figures in the CIO template, read in your browser only and never published. Steps below.

How a published report gets onto the slides

It's all done on GitHub, in a browser. You need a GitHub account with access to the project.

  1. Copy the new report's PDF link from lacera.gov.

  2. On GitHub, open Actions → CIO report, choose Run workflow and paste the link.

    GitHub downloads the PDF, reads it and checks its totals (a report that fails a check is rejected, never patched by hand), pulls the FRED figures as of the report's date, and proposes the update.

  3. Open the proposed update and type in the written parts: dollar index, themes, items for attention. Its instructions link straight to the file.

  4. When its checks turn green, merge it. The site publishes within minutes.

Build the slides from the template

Use this to prepare a month's slides from your team's own figures, before the report is published. You don't need the PDF or a GitHub account.

  1. Download the CIO template (Excel).

    To see a finished one, open the filled example. It holds the latest published report.

  2. Fill in the yellow cells on the Report, Pension, OPEB, Markets, Macro and Items tabs.

    Percent as printed (0.1 means 0.1%), money in $ millions. Leave a cell empty when the report has no figure.

  3. Open the Checks tab. Every line should say OK.

    It tests what every published report satisfies: weights add to 100%, categories add to the fund total, the return histogram adds to 120 months, and every return has a benchmark.

  4. Open the Export tab, then File → Save As → CSV UTF-8 (Comma delimited).

    Excel saves only the tab that's open, so make sure it's Export.

  5. On the CIO Monthly tab, click Open a template file and pick the CSV.

    The tabs and slides build from it, marked "template file, not published" everywhere. If anything in the file is wrong, nothing is shown and the page lists what to fix. Close file puts the published report back.

The file is read in your browser only. It is never uploaded, saved or published, and closing or reloading the page clears it. Until LACERA publishes the report its figures are confidential: keep the files on the team's systems, and don't use the GitHub form or AI tools for them.

How the slides work

  • The slides are one web page, app/public/deck/index.html. No server, no database, no login.
  • Every number sits in one block in that page, written by the program. The rest draws the charts and writes each slide's headline from those numbers, so nothing is retyped each month.
  • The dashboard's CIO Monthly tab shows the same page and hands it the month picked on the slider, so any report can be presented.
  • Keys: → ← to move, E to switch fund, N for speaker notes, F for full screen.
